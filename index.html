University Capstone Project • AI for Cyber Security

Malicious URL Detection Using Machine Learning

URLGuard is a cyber threat defense application designed to accurately identify phishing, deceptive, and malicious web locations in real time using extracted lexical and structural markers.

!

The Cyber Threat Problem

Phishing URLs are engineered to deceive users and redirect them to fraudulent login pages, credential harvesters, or malware download drops. Modern attackers frequently employ algorithmic URL generators, deep subdomain nesting, and typosquatting that bypass simple blacklist defenses.

🎯

Core Project Objective

Develop an end-to-end machine learning pipeline that extracts 54 distinct features from input URLs and accurately predicts binary threat classifications (Legitimate vs Phishing) with explainable risk indicators for security operations analysts.
